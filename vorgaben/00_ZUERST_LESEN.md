# Brain Food – aktuelles Projektpaket für Claude Code

Dieses ZIP enthält **nur den vereinbarten Projektstand** – keine alten Text-/PowerPoint-Entwürfe.

## So verwendest du es
1. ZIP entpacken.
2. Claude Code im Repository/Projektordner starten, in dem die Subdomain umgesetzt werden soll.
3. Claude Code zuerst `01_PROJEKTBRIEF-UND-STARTPROMPT.md` lesen lassen.
4. Danach auf `02_Sprechtext/Sprechtext-abgestimmt.txt`, `02_Sprechtext/content.json` und die drei nummerierten PNG-Wireframes unter `03_Wireframes/` verweisen.

## Enthalten
- Vereinbartes Zielbild: gamifizierte Präsentation als kleines Browsergame.
- Ablauf der drei Bildschirme und Bedienung (manuell oder Autopilot, jederzeit pausierbar).
- Aktueller, vorläufig abgestimmter Sprechtext: 504 Wörter, in TXT und JSON.
- Drei Spielfeld-/Bildschirm-Wireframes, Compiler-Animationsgrafik und vorhandener HTML-Animationsprototyp.
- Medienhinweise: Audio und finale Beispielbilder werden später ergänzt.

## Nicht enthalten
Es gibt noch keine selbst eingesprochenen Audiodateien oder finalen Beispielbilder. Bis dahin soll Claude Code mit Textmodus und klar markierten Bild-Platzhaltern arbeiten.
